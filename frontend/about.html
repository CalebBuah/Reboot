About Reboot

A local router watchdog and relay recovery system.

System architecturev1.0

Reboot combines an ESP32 watchdog, an Express API, SQLite persistence, and a browser dashboard. The ESP32 monitors connectivity and controls the relay; the backend stores state, logs, and commands; the dashboard provides authenticated visibility and control.

Safety boundaryProtected

Browser control endpoints require an authenticated session. ESP32 endpoints require the device token. Restart commands are rate-limited and queued for device execution.
